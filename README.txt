HƯỚNG DẪN SỬ DỤNG & TRIỂN KHAI MIỄN PHÍ:
1. Xem trực tiếp: Giải nén file ZIP và mở file index.html bằng trình duyệt bất kỳ.
2. Bổ sung thêm ảnh (nếu muốn đủ 7 ảnh): Chép thêm ảnh vào thư mục assets/images/ hoặc nhấn nút "+ Thêm ảnh kỷ niệm khác của cô" trực tiếp trên trang web.
3. Đưa lên mạng miễn phí (Vercel / Cloudflare Pages): Kéo thả toàn bộ thư mục website-tri-an-20-11 lên Vercel hoặc Cloudflare Pages là có link chia sẻ ngay lập tức.
